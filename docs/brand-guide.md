# Mitran Brand Guidelines

## Logo

The Mitran mark is a stylized "M" formed by two connected peaks meeting at a central point, evoking handshake/friendship. A soft dot above the center represents connection.

**Files:** `assets/logo.svg`

### Usage Rules

- Minimum size: 24×24px
- Clear space: 1× the height of the mark on all sides
- Never rotate, stretch, or recolor outside approved palette
- On dark backgrounds, use white (#f1f5f9) monochrome variant

## Colors

| Role | Hex | Usage |
|------|-----|-------|
| Primary | `#06b6d4` | Logo, buttons, links, accents |
| Secondary | `#0891b2` | Hover states, gradients, borders |
| Dark BG | `#0f172a` | Dashboard background, dark mode |
| Light BG | `#f8fafc` | Page backgrounds, cards |
| Text Dark | `#1e293b` | Body text on light backgrounds |
| Text Light | `#f1f5f9` | Body text on dark backgrounds |

## Typography

| Context | Font | Weight |
|---------|------|--------|
| UI headings | Inter | 600–700 |
| UI body | Inter | 400 |
| Code / terminal | JetBrains Mono | 400 |

## Spacing

Base unit: **4px**. All spacing uses multiples: 4, 8, 12, 16, 24, 32, 48, 64.

## Voice

Concise, technical, friendly. Mitran means "friend" — the brand is approachable but never informal in documentation.
