Mitran

Agent-Native Company Infrastructure

Open-source platform where AI agents run your DevOps, CI/CD, docs, tickets, and ops — so your team focuses on building product.

GitHub → Quick Start

Core Capabilities

5 AI Agents

Dev, Ops, CI/CD, Docs, Tickets — each autonomous, all coordinated.

OpenClaw Runtime

Persistent memory, cron jobs, subagents, and multi-session orchestration.

MCP Protocol

Connect any tool via Model Context Protocol. User-managed servers.

Multi-LLM

Swap providers (Bedrock, OpenAI, local) per agent without code changes.

Quick Start

git clone https://github.com/getmitran/mitran.git
cd mitran
make up          # Docker Compose: engine + agents + dashboard
mitran init      # Describe your company → agents set up everything

Zero to deployed in 30 minutes. Self-hosted. Your data stays yours.
