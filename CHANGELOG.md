# Changelog

## [0.1.0] - 2024-06-18

### Added
- Go DAG engine with scheduler, priority queue, resource locks
- 8 AI agents (Dev, Docs, Ops, Review, HR, CI/CD, Tickets, Wiki)
- React dashboard with Kanban, Chat, Tickets, Wiki, Sessions, Agents
- gRPC protobuf contracts for Go<->Python IPC
- WebSocket real-time updates
- Memory system (facts, episodes, corrections, FTS search)
- JWT authentication with roles (admin/operator/viewer)
- Session manager with persistent chat history
- Streaming LLM responses via SSE
- Cron scheduler for recurring agent jobs
- Subagent pool for parallel dispatch
- Event bus with pub/sub + SSE streaming
- GitHub integration (PRs, branches, workflows)
- Slack integration (messages, channels)
- MCP client library + server registry
- Plugin system with hot-reload
- Rate limiting, response caching, request tracing
- Approval workflow with checkpoints
- Notification system (WebSocket, Slack, webhook)
- Docker Compose + Dockerfiles
- GitHub Actions CI pipeline
- Kubernetes deployment manifests
- Comprehensive documentation (API, security, deploy, contributing)
